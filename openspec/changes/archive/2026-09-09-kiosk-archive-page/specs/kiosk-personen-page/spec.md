## ADDED Requirements

### Requirement: Archiv button below the Events button

The `KioskPersonen` page SHALL show a fourth navigation button, labeled
"Archiv", positioned directly below the "Events" button and matching its width.
Tapping it SHALL open the archive page.

#### Scenario: Button shown below the Events button
- **WHEN** the user views the `KioskPersonen` page
- **THEN** an "Archiv" button is shown directly below the "Events" button, the
  same width as the other buttons in that column

#### Scenario: Opening the archive page
- **WHEN** the user taps the "Archiv" button
- **THEN** the archive page opens
